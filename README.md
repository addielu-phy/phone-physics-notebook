# 手機物理實驗室

把手機變成物理實驗器材：手機負責感測，電腦負責即時繪圖與分析。純前端網頁，免安裝、免登入，量測數據只在手機與電腦之間點對點傳輸，不上傳伺服器。

線上版：<https://addielu-phy.github.io/phone-physics-notebook/>

製作：盧政良（高雄中學物理科）

## 目前功能（里程碑 2）

- **首頁**：22 個實驗的目錄，可依分類篩選或搜尋。已開放單擺測 g、彈簧振動（含彈簧常數）、向心加速度（含向心半徑擬合）、聲音頻譜，其餘標示為「即將推出」。
- **彈簧振動與彈簧常數**（加速度計）：手機掛在彈簧下振動，自動選軸、以自相關求週期 T，算出 k = 4π²m/T² 與位移振幅；多種質量自動畫 T²–m 圖並線性擬合，由斜率求 k、由截距估計彈簧等效質量。
- **向心加速度**（加速度計＋陀螺儀）：手機平放在轉盤上，同時記錄 |ω| 與水平加速度；把加速度投影到指向圓心的主成分方向，對 ω² 做直線擬合，斜率即半徑 r，並與尺量的 r 比較。顯示手機靜止時的傾角，提醒平放。
- **聲音頻譜**（麥克風）：手機端以 Web Audio 計算 FFT（8192 點），只把頻譜傳到電腦（不傳錄音）；電腦即時顯示頻譜、基頻 f₀、音名與 f₀(t) 歷程；記錄時平均頻譜並列出各泛音 fₙ/f₀ 與相對強度；選填空氣柱長度與管徑可由閉管共鳴算聲速。
- 新實驗台皆可匯出 CSV（摘要、原始數據，UTF-8 BOM，Excel 直接開啟）與多工作表 Excel，也都有示範模式。
- **單擺測 g**：
  - 電腦顯示 QR Code，手機掃描後自動配對連線
  - 即時角速度圖（陀螺儀三軸），可開始、暫停、繼續、結束
  - 以自相關求出週期 T，輸入擺長 L 後計算 g = 4π²L / T²
  - 多輪紀錄（最多 20 輪），自動計算平均與標準差
  - 匯出 Excel（說明、多輪摘要、每輪原始數據）
- **示範模式**：沒有手機也能試用，以合成的單擺數據展示完整流程，畫面與匯出檔都會標示「示範」。
- 亮色／暗色主題，手機與電腦皆可瀏覽。

## 使用方式

1. 在電腦開啟網站，進入「單擺測 g」。
2. 用手機相機掃描畫面上的 QR Code，在手機上按「啟用感測器」（iPhone 需允許「動作與方向」權限）。
3. 把手機牢固地綁在擺錘上，量好擺長 L 並輸入。
4. 拉開小角度（建議 15° 以內）放手，在電腦按「開始」，擺動數個週期後按「結束並記錄」。
5. 重複多輪後按「匯出 Excel」。

> 手機頁面需在 HTTPS 下才能讀取感測器與麥克風；量測時請讓手機頁面保持在前景、不要鎖定螢幕。
> iPhone 需允許「動作與方向」（彈簧、向心）或「麥克風」（聲音頻譜）權限；若曾按過拒絕，需完全關閉 Safari 或到設定中重新允許。
> 若學校網路封鎖點對點連線，手機與電腦可能無法配對，可改用手機熱點。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 分析函式單元測試
npm run build    # 輸出到 dist/
npm run preview  # 預覽建置結果（port 4173）
```

網址加上 `?debug` 可在瀏覽器主控台看到連線除錯訊息。`tests/` 內有以 Playwright 撰寫的端對端測試腳本（`e2e_m2.py` 測試三個新實驗台的示範、匯出、手機版面，並以模擬感測器與假麥克風完成配對串流）。

手機頁網址為 `?sensor=配對碼&exp=實驗代號`，手機依 `exp` 決定讀取陀螺儀、加速度計、兩者或麥克風。

使用的開源套件：Vite、TypeScript、Chart.js、PeerJS、qrcode、SheetJS。
