# 手機物理實驗室

把手機變成物理實驗器材：手機負責感測，電腦負責即時繪圖與分析。純前端網頁，免安裝、免登入，量測數據只在手機與電腦之間點對點傳輸，不上傳伺服器。

線上版：<https://addielu-phy.github.io/phone-physics-notebook/>

## 目前功能（里程碑 1）

- **首頁**：22 個實驗的目錄，可依分類篩選或搜尋。目前開放「單擺測 g」，其餘標示為「即將推出」。
- **單擺測 g**：
  - 電腦顯示 QR Code，手機掃描後自動配對連線
  - 即時角速度圖（陀螺儀三軸），可開始、暫停、繼續、結束
  - 以自相關求出週期 T，輸入擺長 L 後計算 g = 4π²L / T²
  - 多輪紀錄（最多 20 輪），自動計算平均與標準差
  - 匯出 Excel（說明、多輪摘要、每輪原始數據）
- **示範模式**：沒有手機也能試用，以合成的單擺數據展示完整流程，畫面與匯出檔都會標示「示範」。
- 亮色／暗色主題，手機與電腦皆可瀏覽。

## 使用方式

1. 在電腦開啟網站，進入「單擺測 g」。
2. 用手機相機掃描畫面上的 QR Code，在手機上按「啟用感測器」（iPhone 需允許「動作與方向」權限）。
3. 把手機牢固地綁在擺錘上，量好擺長 L 並輸入。
4. 拉開小角度（建議 15° 以內）放手，在電腦按「開始」，擺動數個週期後按「結束並記錄」。
5. 重複多輪後按「匯出 Excel」。

> 手機頁面需在 HTTPS 下才能讀取感測器；量測時請讓手機頁面保持在前景、不要鎖定螢幕。
> 若學校網路封鎖點對點連線，手機與電腦可能無法配對，可改用手機熱點。

## 開發

```bash
npm install
npm run dev      # 開發伺服器
npm test         # 分析函式單元測試
npm run build    # 輸出到 dist/
npm run preview  # 預覽建置結果（port 4173）
```

網址加上 `?debug` 可在瀏覽器主控台看到連線除錯訊息。`tests/` 內有以 Playwright 撰寫的端對端測試腳本。

使用的開源套件：Vite、TypeScript、Chart.js、PeerJS、qrcode、SheetJS。
